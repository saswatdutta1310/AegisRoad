# AegisRoad v3.0 — UI/UX Website

A single-file HTML/CSS/JS website for the AegisRoad civic road safety platform, designed in the style of the Rapida delivery website reference (bold teal/yellow palette, Barlow Condensed typography, 3D animated cards, spin badges, scroll reveal, ticker tape).

## Open
Just open `index.html` in any modern browser — no build step required.

## Sections
1. **Hero** — 3D animated road card with hazard pings, parallax bg text, mouse-tilt
2. **Commitment** — Stats grid: 6 defect classes, 26K+ training images, 24/7 monitoring
3. **Platform Modules** — Accordion: Edge AI, Command Center, Drive Mode, AegisChat, SpendWatch, Contractor Portal
4. **Ticker + Approach** — Scrolling ticker + feature list
5. **User Roles** — Government Officer, Contractor, Field Worker, Citizen, Edge AI, AegisChat
6. **SpendWatch** — Formula display + 4-factor weight breakdown
7. **Blockchain** — Proof of Repair 6-step pipeline + TX hash mock
8. **BIMSTEC Coverage Map** — Animated map pins
9. **Tech Stack** — 8-card grid (React, FastAPI, YOLOv8, Claude, Avalanche, JWT, Vercel, Render)
10. **FAQ** — 6 accordion questions
11. **CTA + Footer**

## Design
- Colors: Deep Teal `#0B4438`, Acid Yellow `#C8D400`, Warm Cream `#F4F0E6`
- Fonts: Barlow Condensed (display), Inter (body)
- Animations: 3D hero card float, hazard pings, spin badges, scroll reveal, parallax, ticker
