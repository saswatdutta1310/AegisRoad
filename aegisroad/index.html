AegisRoad's

Modules

Six integrated modules form a complete civic infrastructure command platform — from AI detection to immutable on-chain verification.

01.
Edge AI — YOLOv8 Hazard Detection
YOLOv8-Nano trained on RDD2022 (26,869 images, 6 countries) classifies four defect classes: D00 Longitudinal Cracks (7-day SLA), D10 Transverse Cracks (72h), D20 Alligator Cracking (48h), and D40 Potholes (24h critical). Live GPS captures coordinates and auto-pins hazards to the public map via reverse geocoding.
🤖
02.
Command Center — Government Dashboard
Municipal officers review the full hazard queue, assign contractors, and trigger SLA countdown timers. Real-time status updates flow through a 30-second polling loop on the live hazard context. Full control over triage, reassignment, and escalation — all from one dashboard.
🏛️
03.
Drive Mode — V2I Alert System
Real GPS tracking via watchPosition with a 500m geofence radius checks against all known hazards. Bilingual voice alerts in English and Hindi via the Web Speech API. Simulation mode follows the demo NH-16 Vijayawada route. Phone vibration patterns by severity: Critical 5 pulses, High 3, Medium 2.
🚗
04.
AegisChat — Claude Sonnet 4 AI Assistant
RAG-grounded assistant queries the live hazard database before every response. Full session persistence stored in DB and restored across page reloads. Thumbs-up/down feedback loop via POST /api/v1/chat/feedback. Fallback responses prevent off-topic hallucination — powered by Anthropic's Claude Sonnet 4.
💬
05.
SpendWatch — Financial Accountability
Four-factor efficiency scoring: SLA compliance (40%), budget efficiency (30%), work quality (20%), and civic rating (10%). Live disbursement tracking per contractor, CSV audit export, and a contractor leaderboard ranked by efficiency score. SLA breach triggers automatic re-assignment.
💰
06.
Contractor Portal — Job Queue Management
Contractors view their assigned job queue with SLA deadlines and penalty exposure visible before breach. Field workers navigate to hazard locations, log arrival, capture photo evidence, and submit completion — all from the Driver Mobile HUD optimized for field use.

FAQ
What is AegisRoad? +
AegisRoad is a full-stack civic-tech platform for municipal officers, field drivers, and contractors. It combines YOLOv8 road defect detection, Claude Sonnet 4 AI assistance (AegisChat), and role-based dashboards into one command-and-control system for detecting hazards, dispatching repairs, and anchoring proof-of-repair on the Avalanche blockchain.
How does YOLOv8 hazard detection work? +
Upload any dashcam or road image and YOLOv8-Nano (trained on RDD2022 — 26,869 images across 6 countries) classifies defects as D00 Longitudinal Crack, D10 Transverse Crack, D20 Alligator Cracking, or D40 Pothole. The model is hosted on Hugging Face Spaces. Live GPS captures lat/lng at upload, and reverse geocoding via Nominatim resolves the road name. The hazard is auto-created in the database and immediately visible on the public map.
What is Proof of Repair and why blockchain? +
Proof of Repair anchors a SHA-256 hash of the repair evidence (image URL + GPS coordinates) onto the Avalanche Fuji Testnet via the ProofOfRepair.sol smart contract. This creates a tamper-proof, publicly verifiable record of every repair — preventing fraudulent spend claims and holding contractors accountable without trusting any central authority. The transaction hash is stored in the database for full audit trail.
How does the SLA system work? +
Each hazard class carries an SLA: D40 Potholes (Critical) must be repaired in 24 hours; D20 Alligator Cracking (High) in 48 hours; D10 Transverse Cracks (Medium) in 72 hours; D00 Longitudinal Cracks (Low) in 7 days. When a government officer assigns a contractor in the Command Center, the SLA countdown timer starts. Contractors see their penalty exposure before breach. Missed SLAs trigger re-assignment and affect the SpendWatch efficiency score.
Can I run AegisRoad locally? +
Yes — Node.js 18+ and Python 3.11+ are all you need. Clone the repo, run start-all.ps1 on Windows (or start backend and frontend manually), fill in your .env with an Anthropic API key and optionally blockchain credentials. The app runs fully without blockchain credentials — those features are silently disabled when env vars are missing. Access the frontend at localhost:3000 and Swagger docs at localhost:8000/docs.
Why choose AegisRoad for civic infrastructure? +
AegisRoad is the only platform combining AI detection, SLA enforcement, blockchain proof-of-repair, and financial accountability in a single system built for municipal scale. It reduces manual inspection costs, prevents fraudulent contractor claims, provides taxpayers with a verifiable public audit trail, and scales from a single city to all BIMSTEC nations with the same codebase.
